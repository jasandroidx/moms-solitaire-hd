## 2025-05-18 - Solitaire ARIA Dialog & Keyboard Hints
**Learning:** Pure HTML dialog overlays require explicit `role="dialog"`, `aria-modal="true"`, and `aria-labelledby`/`aria-label` bindings for screen reader accessibility when CSS overlays simulate modal popups. Button tooltips detailing keyboard shortcuts (`(N)`, `(U)`, `(H)`) improve discoverability without adding UI clutter.
**Action:** When working on HTML-based game overlays or custom modals, ensure dialog accessibility attributes and shortcut discoverability hints are always added to the modal markup and action buttons.
